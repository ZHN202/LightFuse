# LightFuse project page

Static project page for **LightFuse: Relightable Interactive Gaussian Scene Reconstruction via Multi-Scan Fusion and 2D Gaussian Ray Tracing**. The page follows the original IGFuse/Nerfies academic-project template and includes the LightFuse demo video, scene-editing renders, method overview, and experimental results.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

The included manuscript is an anonymous review submission and is intentionally kept as a local project asset. Update the author list, publication links, and BibTeX after acceptance and before public deployment.
